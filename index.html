📋 获取 Cookie 步骤
⚠️ 登录后页面可能显示404，这是正常的，cookie 已经在浏览器里了
1. 点击「🔗 打开2dfan」→ 输入账号密码登录
2. 登录后（即使看到404也没关系），按 F12 打开开发者工具
3. 切到 Network 标签 → 按 F5 刷新页面
4. 点击列表中任意一个请求
5. 右侧找到 Request Headers → 找到 cookie: 这一行
6. 双击选中 cookie: 后面的整个值（很长的一串），右键复制
7. 粘贴到上方输入框 → 自动保存 → 点「🔍 验证」确认
